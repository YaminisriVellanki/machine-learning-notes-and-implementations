 Introduction to Machine Learning

## 1. What is Machine Learning?
Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

## Example:
A model can learn from previous house prices and predict the price of a new house.

 ## 2. Why Machine Learning?
Traditional programming requires manually defined rules.
Machine Learning allows computers to learn patterns from historical data and use those patterns to make predictions on new data.

 Traditional Programming
Rules + Data → Output
Machine Learning
Data + Output → Learn Patterns

Deep Learning (DL): A subset of ML that uses multi-layer neural networks

## 4. Types of Machine Learning
Machine Learning is mainly divided into three types:
## Supervised Learning
The model learns from labeled data, where the correct output is already known.
Main types:
•	Classification
•	Regression
Examples:
•	Spam detection
•	House price prediction
•	Student result prediction
## Unsupervised Learning
The model learns patterns or structures from unlabeled data.
Main techniques:
•	Clustering
•	Dimensionality Reduction
Examples:
•	Customer segmentation
•	Grouping similar customers
## Reinforcement Learning
An agent learns by interacting with an environment and receiving rewards or penalties.
Examples:
•	Game playing
•	Robotics
•	Autonomous systems

## 5. Classification vs Regression
Classification	                      Regression
Predicts a class or category	   Predicts a numerical value
Output is discrete	             Output is continuous
Spam / Not Spam	                 House Price
Pass / Fail	                     Salary

## 7. Basic Machine Learning Terminology
Term	Meaning
Dataset: 	A collection of data used for analysis and model building
Feature:  An input variable used by the model
Target:   The output variable that the model predicts
Model:   	A system that learns patterns from data
Training Data: Data used to train the model
Testing Data: 	Data used to evaluate the model
Prediction:  Output produced by the trained model
## Example
Consider the following dataset:
Age	Salary	Experience	Purchased
25	30000	    2	            No
35	60000	    8	            Yes
Here:
Features → Age, Salary, Experience

Target → Purchased
